# Task 4

Программа считывает данные с USB-камеры и трех датчиков `SensorX` в отдельных потоках. В главном потоке берутся последние доступные значения из очередей и выводятся поверх кадра с камеры.

`SensorX` не изменялся. Используются три датчика:

- `SensorX(0.01)` — примерно 100 Гц;
- `SensorX(0.1)` — примерно 10 Гц;
- `SensorX(1)` — примерно 1 Гц.

Очереди имеют размер `1`, чтобы хранить только самое свежее значение. Если датчик выдал новое значение, а старое еще не забрали, старое значение заменяется новым. Так уменьшается задержка отображения.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

Обычный запуск с камерой по индексу `0`:

```bash
python main.py
```

Запуск с указанием камеры, разрешения и частоты отображения:

```bash
python main.py --camera 0 --resolution 640 480 --fps 30
```

Для Linux можно указать имя устройства камеры:

```bash
python main.py --camera /dev/video0 --resolution 1280 720 --fps 30
```

## Аргументы

- `--camera` — индекс или имя камеры. Примеры: `0`, `1`, `/dev/video0`.
- `--resolution` — желаемое разрешение в формате `WIDTH HEIGHT`, например `640 480`.
- `--fps` — частота обновления окна.

## Логи

Ошибки камеры, окна и потоков записываются в файл:

```text
log/task4.log
```
