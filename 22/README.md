# Комплект решений по заданиям из Tasks.pdf

Архив содержит три отдельные папки:

- `task1` — OpenMP-версия умножения матрицы на вектор с параллельной инициализацией.
- `task2` — OpenMP-версия численного интегрирования с `#pragma omp atomic` и локальной переменной.
- `task3` — OpenMP-реализация лабораторной работы №2, метод простой итерации, два варианта распараллеливания и исследование `schedule`.

Для каждой папки добавлены:

- `CMakeLists.txt`
- исходники на C++ (`src/*.cpp`)
- скрипты для серии запусков на сервере
- шаблоны CSV
- PDF-шаблон отчёта и генератор итогового PDF
- `README.md` с командами сборки и запуска

## Важно

Замеры по условиям задания нужно проводить на сервере. Поэтому в архив включены:

- готовые программы,
- готовые скрипты для экспериментов,
- шаблоны отчётов,
- генераторы финальных PDF после заполнения CSV результатами серверных запусков.
