# Параллельное программирование — задания 1, 2, 3

В репозитории находятся три независимые программы:

- `1/` — **Задание 1**: умножение матрицы на вектор с параллельной инициализацией массивов;
- `2/` — **Задание 2**: численное интегрирование с OpenMP (`#pragma omp atomic` + локальная переменная);
- `3/` — **Задание 3**: лабораторная работа №2, решение СЛАУ **методом простой итерации** с OpenMP в двух вариантах.

Для каждого задания есть своя папка с исходным файлом программы (`main.c` или `main.cpp`) и `CMakeLists.txt`.

## Требования задания

Согласно условию:

1. программы должны собираться при помощи **make** или **cmake**;
2. к работе должна быть приложена **ссылка на GitHub** с исходным кодом;
3. **все вычисления проводить на сервере**;
4. результаты оформить и сохранить в **PDF**.

## Структура проекта

```text
.
├── 1/
│   ├── main.c
│   └── CMakeLists.txt
├── 2/
│   ├── main.c
│   └── CMakeLists.txt
├── 3/
│   ├── main.cpp    # если задача 3 оформлена на C++
│   └── CMakeLists.txt
└── README.md
```

> Если в папке `3/` исходный файл называется не `main.cpp`, а иначе, нужно отразить это в `CMakeLists.txt`.

# 6. Задание 3 — лабораторная работа №2

## Постановка

По условию необходимо:

- выполнить лабораторную работу №2;
- использовать **метод простой итерации**;
- написать код на **C++**;
- распараллелить последовательную программу решения СЛАУ вида `Ax = b` с помощью OpenMP;
- реализовать **два варианта программы**:
  1. для каждого распараллеливаемого цикла создается отдельная секция `#pragma omp parallel for`;
  2. создается одна общая секция `#pragma omp parallel`, охватывающая весь итерационный алгоритм;
- замерить время работы двух вариантов программы при различном числе ядер: **от 1 до числа доступных в узле**;
- построить графики:
  - времени работы,
  - ускорения,
  - эффективности;
- исследовать оптимальные параметры `#pragma omp for schedule(...)` при фиксированном размере задачи и количестве потоков;
- сделать вывод о целесообразности использования первого или второго варианта программы.

## Исходные данные задачи

- элементы главной диагонали матрицы `A` равны `2.0`;
- остальные элементы матрицы равны `1.0`;
- все элементы вектора `b` равны `N + 1`;
- точное решение системы — вектор, все элементы которого равны `1.0`;
- начальное приближение `x` можно взять равным `0`.

## Важное замечание

В условии прямо сказано, что для задачи 3 нужно использовать **C++**.

Если в папке `3/` лежит `main.c`, а не `main.cpp`, то:
