# Архив по трём заданиям

В архиве три папки:
- `task1_matrix_vector`
- `task2_integration`
- `task3_linear_system`

Подготовлены:
- C++-программы,
- `CMakeLists.txt`,
- шаблоны CSV,
- шаблоны графиков в PDF,
- шаблоны отчётов в PDF,
- README с командами сборки и запуска.

Важно: по условиям работы вычисления нужно выполнять на сервере. Поэтому реальные таблицы и графики в архиве сейчас оставлены как шаблоны, которые нужно перегенерировать после запусков.
