# Задание 1: анализ эффективности умножения матрицы на вектор

## Что реализовано

Программа `matrix_vector_benchmark` выполняет задание 1 из Task3.pdf:

- использует C++20 и `std::thread`;
- параллельно инициализирует матрицу, вектор и результат;
- умножает матрицу `N x N` на вектор длины `N`;
- проводит замеры для размеров `20000x20000` и `40000x40000`;
- проводит замеры для потоков `1,2,4,7,8,16,20,40`;
- сохраняет таблицу результатов в CSV;
- считает ускорение относительно запуска на 1 потоке;
- содержит скрипт для построения графика ускорения.

## Сборка

```bash
cmake -B build -S . -DCMAKE_CXX_COMPILER=g++
cmake --build build -j
```

## Запуск полного задания на сервере

```bash
./build/matrix_vector_benchmark \
  --sizes 20000,40000 \
  --threads 1,2,4,7,8,16,20,40 \
  --output results/task1_matrix_vector.csv
```

Матрица `40000x40000` типа `double` занимает примерно 12.8 GB памяти только под матрицу, поэтому запускать полный вариант нужно на сервере.

## Быстрый тест на локальном компьютере

```bash
./build/matrix_vector_benchmark --sizes 1000 --threads 1,2,4 --output results/test.csv
```

## Построение графика

```bash
python3 scripts/plot_speedup.py results/task1_matrix_vector.csv results/speedup.png
```

## Формулы для отчета

Последовательное время для размера `n`:

```text
T1(n) = время выполнения программы на 1 потоке
```

Параллельное время:

```text
Tp(n, p) = время выполнения программы на p потоках
```

Ускорение:

```text
Sp(n) = T1(n) / Tp(n, p)
```

В CSV есть два ускорения:

- `multiply_speedup` — ускорение только умножения;
- `total_speedup` — ускорение инициализации + умножения.

Для графика обычно берется `multiply_speedup`, потому что в задании анализируется именно умножение матрицы на вектор, а инициализация нужна как обязательная параллельная часть программы.
